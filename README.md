# Asynchronous Fast Adaptive Composite grid method solver
Asynchronous Fast adaptive composite Grid solver for partial differential equations allowing variational formulation. Writen in Fortran using Coarrays for distributed memory parallelism. This project is not yet completely finished the unit testing is still a work in progress as well and should be finished shortly.
